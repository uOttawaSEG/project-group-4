## **Online Tutoring Appointment Management System (OTAMS)**
### An Android mobile application that streamlines  tutoring appointment scheduling

---

It supports three user-roles: Student, Tutor, and Administrator, each with distinct permissions and views, requiring role-based access control and real-time data synchronization across users.



OTAMS was built collaboratively using **Git** for version control, with **CircleCI** for continuous integration.


---

**Tech Stack**
- **Application**: Java, Android SDK, XML
- **Database & Auth**: Firebase Realtime Database, Firebase Authentication
- **Tools**: Git, GitHub, Android Studio
